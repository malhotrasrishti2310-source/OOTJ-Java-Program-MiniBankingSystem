# Mini Banking System

## Overview
The Mini Banking System is a desktop-based banking application developed using Java. It provides a graphical user interface (GUI) that allows users to perform basic banking operations such as depositing money, withdrawing money, checking account balances, and viewing account details.

The application is developed using Java Swing and demonstrates the implementation of Object-Oriented Programming concepts.

## Features
- View available account balance.
- Deposit money into the account.
- Withdraw money with balance validation.
- Display account holder details.
- Maintain transaction history.
- Validate user input and handle invalid transactions.
- Interactive graphical user interface.

## Technologies Used
- Java
- Java Swing
- Java AWT
- Eclipse IDE

## How to Run
1. Clone or download this repository.
2. Open Eclipse IDE.
3. Import the project into Eclipse or create a new Java project.
4. Add all three Java files to the source folder.
5. Open `Main.java`.
6. Run the program as a Java Application.

## Objective
The objective of this project is to understand and implement Object-Oriented Programming concepts in Java by developing an interactive banking application with basic financial operations.
